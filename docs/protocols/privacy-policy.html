特别提示

花拾归匣由${name}运营。我们深知个人信息对你的重要性，会按照法律法规要求采取相应的安全保护措施，尽力保护你的个人信息安全。

在你使用花拾归匣前，请仔细阅读并理解本政策。涉及敏感个人信息、对外提供个人信息、账号注销等重要内容，我们会以加粗、弹窗或其他合理方式提示你。你同意本政策后，我们才会开始处理实现功能所必需的信息。

花拾归匣提供两种使用方式：

  • 账号模式：使用中国大陆手机号注册或登录，数据可以同步到云端；
  • 游客模式：无需注册即可使用部分功能，数据只保存在你的设备本机，最多可先记录 3 件物品。游客模式下我们不会向服务器上传你的账号信息、物品数据或图片。

一、我们收集哪些信息及用途

我们坚持必要和最小范围原则，只处理实现具体功能所需的信息。

1. 手机号

用于注册、登录、验证码发送、账号识别、数据隔离、找回账号和账号安全。未注册手机号在完成验证并同意本协议后，会直接创建账号。

2. 登录密码和短信验证码

用于身份验证。密码在传输前会加密处理，短信验证码设有有效期与发送频率限制，我们不会将明文密码用于其他用途。

3. 用户名、头像、生日和性别

用于展示个人资料和完善账号信息。生日和性别为选填项，不填写不影响物品记录、收纳、洞察等核心功能。

4. 物品与生活资产管理信息

包括物品名称、分类、图片、购入价、当前估值、购入日期、购买渠道、保修期、目标使用天数、使用方式与次数、收纳位置、当前状态、状态变更记录、备注、标签、关联物品、收藏情况，以及心愿匣、徽章、闲置回血计划等数据。上述信息用于提供物品登记、展示、统计、提醒、同步与洞察功能。

5. 你主动上传的图片

当你更换头像或添加物品图片时，我们会在取得相机或相册权限后读取你主动选择的图片，并上传至云端存储，用于头像展示和物品详情回显。拒绝授权时，你仍可使用不带图片的文本记录功能。

6. 设备与网络信息

为保障登录安全、账号隔离、故障排查和服务稳定，我们可能处理操作系统、设备品牌、应用版本、网络状态、访问时间、IP 地址和接口日志。当前 Android 版本在系统允许时可能尝试获取 OAID、IMEI 等设备标识，未授权、系统不允许或接口无法返回时相应值为空；iOS 版本不获取上述设备标识。我们不会将上述信息用于广告画像，也不会出售给第三方。

7. 本地缓存信息

为保持登录状态和界面偏好，应用会在你的设备本地保存访问凭证、用户资料、皮肤设置、引导状态和筛选偏好。游客模式下，你记录的内容也只保存在本机。你可以通过退出账号、清理应用数据或卸载应用删除本地缓存，但卸载或清理数据可能导致未同步的内容丢失。

二、我们如何取得信息

1. 你主动填写、选择、拍摄或上传的信息；

2. 你使用登录、短信验证码、账号注销、修改资料等功能时产生的信息；

3. 你使用物品、心愿匣、徽章、收藏馆、回血计划及云同步功能时产生的业务记录；

4. 你授权相机、相册等系统权限后，由系统接口提供的信息；

5. 为保障网络和账号安全，由服务器自动记录的网络与日志信息。

三、系统权限

我们仅在具体功能需要时申请权限：

  • 相机：用于拍摄头像和物品照片；
  • 相册/图片读取：用于选择头像、物品图片或心愿图片；
  • 网络权限：用于账号登录、短信验证、数据同步和图片上传；
  • 网络状态：用于判断网络连接情况并处理同步失败。

你可以在系统设置中关闭相关权限。关闭后对应图片功能可能无法使用，但不影响文本记录、数据查看和统计分析等基本功能。当前应用不申请通讯录、日历、麦克风、精确定位等与现有功能无关的权限。

四、游客模式与数据保存位置

1. 游客模式无需注册。你在游客模式下记录的内容仅保存在你的设备本机，不会上传到我们的服务器，也不与任何账号关联；

2. 游客模式下最多可先记录 3 件物品。你可以随时在登录页选择登录或注册账号，继续添加不限件数的物品；

3. 当你从游客模式登录或注册账号后，本机保存的游客物品会在首次同步成功时并入你的账号，并从此按账号模式处理。合并完成后本机会清理这部分游客数据，避免重复导入；

4. 如果你卸载应用、清理应用数据或更换设备，游客模式下尚未同步的数据将无法恢复。

五、第三方服务与信息共享

除以下必要情形外，我们不会向无关第三方出售、出租或共享你的个人信息：

  • 短信服务商：我们委托的短信服务商，用于发送登录验证码；
  • 云存储服务商：阿里云对象存储服务，用于保存你主动上传的头像与物品图片；
  • 后端与云服务商：我们委托的云服务商，用于账号、数据同步和接口服务；
  • 法律法规要求：根据法律法规、司法或行政机关依法提出的要求，或为保护用户、公众及平台合法权益所必需的情形。

我们会在接入第三方服务前评估其个人信息处理行为，并要求其按照约定和法律法规处理相关信息。当前应用未发现广告、行为追踪、个性化广告或向第三方出售个人信息的行为。如果实际接入的服务发生变化，我们会同步更新本政策和商店的数据披露。

六、信息保存期限与存储地点

1. 我们会在实现处理目的所需的最短期限内保存信息，法律法规另有规定的除外；

2. 账号和业务数据原则上保存至你主动删除、注销账号或服务终止；

3. 你删除物品、图片、心愿或注销账号后，我们会删除或匿名化相应数据；因备份、缓存、日志和安全审计等原因无法立即删除的，将在合理期限内处理，并限制其再次用于其他目的；

4. 原则上，我们在中华人民共和国境内处理相关信息。如需跨境传输，我们会依法履行告知、单独同意和安全评估等义务；

5. 发生安全事件时，我们会采取补救措施，并依法向你与相关主管部门告知事件情况及应对建议。

七、你的权利

1. 查阅和更正：你可以在“我的—设置—个人信息”中查看和修改用户名、头像、生日、性别等资料，游客模式需先登录；

2. 删除：你可以在物品、心愿等对应页面删除相关记录；需要删除云端图片或完整数据时，如遇异常可以通过联系邮箱提出申请；

3. 撤回权限同意：你可以在设备系统设置中关闭相机、相册或网络权限。撤回不影响此前基于同意已经完成的处理；

4. 注销账号：你可以在“我的—设置—注销账号”中提交注销。注销前会进行二次确认，注销完成后账号及相关业务数据将按本政策删除或匿名化，法律法规要求保留的除外；

5. 投诉与建议：你可以通过本政策开头列出的联系邮箱或投诉渠道联系我们，我们将在法律规定或合理期限内核查并反馈。

八、账号注销

1. 注销入口：应用内“我的—设置—注销账号”；

2. 注销前请确认你不再需要账号中的物品、图片、心愿、徽章和统计数据，注销后可能无法恢复；

3. 注销时，我们会同步清理你在本机保存的待同步数据与游客数据；

4. 注销完成后，如需再次使用，你可以重新注册账号，但原账号的数据无法找回。

九、未成年人保护

花拾归匣主要面向具备相应民事行为能力的用户。若你未满十八周岁，应在监护人同意和指导下使用；未满十四周岁的儿童，应取得监护人的单独同意。若监护人发现未成年人未经同意使用或提交信息，可以联系我们处理。

十、政策更新

我们可能因服务升级、法律法规变化或数据处理方式调整更新本政策。重大变更会通过弹窗、站内通知或其他显著方式提示；若变更需要重新取得同意，我们会依法另行征得你的同意。本政策更新后，应用会在你再次使用前重新向你提示。
